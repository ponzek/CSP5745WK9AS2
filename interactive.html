🌸 Interactive version 🌸

The paper's figures are static. These views use the same data and the authors' own code. ← back to the reproduction

✨ 1. Spin the covariance stability glyph

Drag to rotate and scroll to zoom. A thin spike means that PCA direction is stable. Wide, flat lobes mean that direction could swing around when the data wiggles, so the 2D PCA picture is less trustworthy.

✨ 2. Watch PCA wobble

Every frame is one possible version of the dataset, drawn from each point's uncertainty. Then PCA is run on that version. This is exactly the authors' sampling pipeline. The paper sums 1,000,000 of these frames into contour lines; here you can watch 300 of them one at a time. The faded trail builds up the cloud that the contours summarize.
